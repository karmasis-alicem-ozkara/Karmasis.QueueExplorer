# KarmasisQueueExplorer

In-house WPF desktop application for exploring and managing MSMQ queues on Windows.

## Current Scope

Phase 1 starts with local MSMQ queue discovery and a dark-themed explorer shell.

## Requirements

- Windows 10/11
- .NET 8 SDK
- MSMQ Windows Feature enabled for real queue discovery

## Build

```powershell
dotnet build
```
